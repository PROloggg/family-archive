# Древо — семейный архив Носковых и Семёновых

Статический сайт на HTML5, CSS и обычном JavaScript. Без фреймворков, сборки, npm, сервера, CDN, внешних шрифтов, аналитики и API.

## Запуск

Откройте index.html двойным щелчком. Интернет нужен только для внешних первоисточников. Сайт работает через file://. Если он уже открыт, обновите страницу после замены файлов.

## Интерфейс

- Полное древо всегда показывает все известные поколения и боковые ветви. Галочек и выбора поколений нет.
- Начальный масштаб —50%. Нажмите + для увеличения и перемещайте схему мышью или пальцем. «Всё древо» снова вписывает её целиком. Работает жест двух пальцев.
- Все люди доступны через список и поиск. Карточка содержит сведения, родственников и документы подряд, без вкладок.
- Основной текст — 24 px. Имена на схеме при масштабе100% —24–28px. При вписывании всей схемы подписи уменьшаются вместе с ней; увеличьте её для чтения.
- Фотографии и сканы показаны целиком, без обрезки. Изображение документа вписывается одновременно по ширине и высоте, без внутренней прокрутки. Для мелких надписей можно скачать оригинал.
- Разделы «Люди», «Хронология», «Архив» показывают полный материал без дополнительных фильтров.
- Поддерживаются клавиатура, Escape, видимый фокус и уменьшенное движение.

Разные даты гибели Алексея, варианты имени жены Петрова и различие между представлением к Славе и награждением медалью сохранены.

Фельдшер из Арлагуля Носкова Александра Фёдоровна исключена пользователем как другой человек. Запись о танковом училище и омская карточка Семёнова1922 остаются наводками. Подробности — UPDATE-2026-11-06.md и archive/new-findings.md.

## Файлы

index.html — запуск. assets/style.css — первоначальное оформление; assets/readable.css и assets/large-type.css — упрощение и крупные шрифты; assets/app.js — взаимодействие; assets/data.js — сведения; assets/thumbs — уменьшенные превью. archive содержит документы, фото, отчёт, GEDCOM и все реестры. manifest.sha256 — контрольные суммы.

В archive находится копия исследовательского дела без служебных Python-скриптов. Исторические HTML-страницы внутри — источники, не зависимости приложения. Оригиналы фото и документов не изменены. Фрагменты для чтения не считаются самостоятельными подтверждениями.

## GitHub Pages

Публикация не выполнялась. Проект содержит частные семейные сведения и фотографии; при публичном размещении они будут доступны посетителям. Скрытие в интерфейсе не скрывает сами файлы. Для сокращённой версии удалите соответствующие данные и исходники из публикуемой копии.

1. Загрузите содержимое этой папки в репозиторий. index.html должен лежать в корне.
2. В Settings → Pages выберите Deploy from a branch, ветку (обычно main) и / (root), сохраните.
3. GitHub выдаст адрес сайта. Относительные пути подходят и для сайта проекта username.github.io/repository/.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site . Ключи и секреты не нужны.

## Обновление

Новые сведения сначала добавляйте в реестры с источниками, затем обновляйте assets/data.js и копии archive. Сохраняйте идентификаторы. Пользовательский текст выводится с HTML-экранированием.

Подходы к навигации изучались по https://www.familysearch.org/en/blog/family-tree-views ; диалоги — по https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/ . Интерфейс создан самостоятельно. Фотографии и исторические документы сохраняют своё происхождение; создание сайта не означает приобретения прав на чужие материалы.

Новые установленные родственники включаются в общую связную схему, в том числе дети боковых ветвей. Для фото из соцсетей указываются ссылка на исходный пост, автор и основание атрибуции. Новых подтверждённых социальных фото на текущем этапе нет.

## Просмотр файлов в окне

В assets/previews.js находятся подготовленные локальные представления TXT, JSON, сохранённых HTML-страниц и DOCX. Из HTML показан текст без выполнения исходных скриптов. Таблицы DOCX извлечены из документа, исходный DOCX доступен для скачивания. В assets/pdf-pages —100 JPEG-страниц Книги памяти; просмотр PDF работает без браузерного PDF-плагина. Можно листать страницы и вводить номер. При открытии Книги памяти выбрана PDF-страница20, соответствующая печатной странице220 с записью Алексея Семёнова.

Файлы превью не являются новыми независимыми историческими источниками и не заменяют оригиналы. Новым данным не приписаны дополнительные доказательства.
